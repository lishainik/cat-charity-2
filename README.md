# QRKot

QRKot - учебный проект: приложение для вымышленного благотворительного фонда поддержки котиков. Фонд собирает пожертвования на корм, медицинское обслуживание, организацию приютов и другие нужды кошачьей популяции.

В приложении можно открывать целевые проекты, то есть сборы конкретной суммы под конкретную задачу, и принимать пожертвования. Пожертвование отправляется в фонд, а не в конкретный проект, и автоматически распределяется по открытым проектам.

## Установка и запуск

после клонирования репозитория нужно создать виртуальное окружение и установить зависимости

```
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

В Windows активация выполняется командой venv\Scripts\activate.

Применяем миграции для создания бд:

```
alembic upgrade head
```

Запуск сервера:

```
uvicorn app.main:app --reload
```

Документация будет доступна по стандартным адресам Swagger - http://127.0.0.1:8000/docs, ReDoc - http://127.0.0.1:8000/redoc.

По умолчанию используется база данных SQLite в файле fastapi.db в корне проекта. Адрес подключения и другие параметры можно переопределить через переменные окружения или файл .env, например:

```
DATABASE_URL=sqlite+aiosqlite:///./my_database.db
```

## Эндпоинты

```
GET    /charity_project/               список всех целевых проектов
POST   /charity_project/               создать целевой проект
PATCH  /charity_project/{project_id}   редактировать целевой проект
DELETE /charity_project/{project_id}   удалить целевой проект
GET    /donation/                      список всех пожертвований
POST   /donation/                      создать пожертвование
```

Ограничения для проектов:

- название уникально, длина от 5 до 100 символов;
- описание не короче 10 символов;
- требуемая сумма - целое число больше 0;
- закрытый проект нельзя редактировать;
- нельзя установить требуемую сумму меньше уже вложенной;
- нельзя удалить проект, в который уже вложены средства.

Сумма пожертвования - целое число больше 0, комментарий необязателен.
